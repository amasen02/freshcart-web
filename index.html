What it is

A zoneless, signal-based single-page application that talks to the YARP gateway and uses HttpOnly session-cookie authentication. It organizes lazy-loaded storefront routes, root signal stores, reusable presentational pieces, and SignalR-based realtime connections.

Who it is for

The storefront is for FreshCart customers using the Angular web application, while maintainers and contributors work on frontend bugs, accessibility improvements, patterns, documentation, tests, linting, and production builds.

Capabilities

customer storefront

Provides the Angular 20 frontend for FreshCart, with lazy-loaded routes covering home, catalog, basket, checkout, orders, account, dashboard, authentication, and support.

HttpOnly session cookie

Uses an HttpOnly, Secure, SameSite session cookie issued through the gateway, keeps access tokens out of JavaScript, and sends the XSRF double-submit header for state-changing requests.

realtime notifications

Connects to the notifications hub with SignalR, updates unread notifications and order-status toasts, observes dashboard refresh ticks, and shows a reconnecting indicator.

SupportChatStore

Opens the support hub when the widget is opened, resumes active sessions, appends server-echoed messages, reports typing state, and supports the role-based agent console.

hardened, non-root nginx image

Builds the static bundle into a hardened, non-root nginx image, while nginx serves the application shell and SPA fallback and Kubernetes routes API and hub traffic.

Architecture

  1. YARP gateway
  2. root @ngrx/signals stores
  3. feature-scoped signal store
  4. SignalrConnectionFactory
  5. cookie-to-JWT BFF exchange
  6. SPA fallback
